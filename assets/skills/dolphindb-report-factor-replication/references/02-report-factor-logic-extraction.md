# 研报因子逻辑抽取

## Skill 介绍

本 Skill 用于研报复现任务的 `pre-result` 阶段。从研报原文中抽取因子定义、变量含义、经济假设和 LaTeX 公式，为后续字段探查、模式判定和 DolphinDB 代码生成提供稳定输入。

## 适用输入

- 研报全文。
- 当前任务因子名。
- 用户补充上下文。
- 可选的资料或文档检索结果。

## 使用流程

1. 定位研报中与当前因子名、中文名、英文缩写、公式编号、变量解释相邻的段落。
2. 抽取因子的金融含义，包括捕捉的市场现象、预期方向和可能影响未来收益的原因。
3. 抽取计算逻辑，包括输入变量、窗口、聚合方式、标准化方式和输出频率。
4. 将公式整理为 LaTeX，变量解释统一放入 `aligned` 环境。
5. 只返回研报已有信息；原文没有给出的内容不得补造。

## 输出格式

```json
{
  "function": "pre-result",
  "args": {
    "description": "因子中文解释、经济含义和计算逻辑",
    "formulation": "LaTeX 公式和变量解释"
  }
}
```

## 约束

- 不进行字段猜测。
- 不生成 DolphinDB 代码。

## 检查清单

- `description` 包含经济含义、变量来源、窗口和输出频率。
- `formulation` 只描述研报已有公式。
- 没有自行补造字段、数据源或计算步骤。
