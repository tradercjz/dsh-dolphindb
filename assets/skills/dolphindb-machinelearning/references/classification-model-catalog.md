# 分类模型目录

默认顺序：

1. `random_forest`：使用 `randomForestClassifier` 的稳健表格数据基线。
2. `logistic_regression`：可用时使用 `logisticRegression` 的可解释二分类基线。
3. `gaussian_nb`：可用时作为快速回退方案。

指标：

- 所有任务报告准确率。
- 二分类任务报告精确率、召回率和 F1。
- 可行时报告类别分布和混淆摘要。

## 模型介绍与适用场景

### `random_forest`

- 模型介绍：基于多棵决策树集成的表格分类模型，能够学习非线性边界和变量之间的交互关系。
- 适用场景：结构化表格分类任务、特征类型混合、希望先建立稳健基线、对线性可分假设不强时优先使用。

### `logistic_regression`

- 模型介绍：经典线性分类模型，输出可解释的线性决策边界和概率分数。
- 适用场景：二分类或近线性可分任务、需要较强可解释性、希望获得线性基线模型时使用。

### `gaussian_nb`

- 模型介绍：基于条件独立和高斯分布假设的朴素贝叶斯分类模型，训练和推理都很快。
- 适用场景：样本量较小、需要快速建立可运行基线、连续特征近似满足分布假设时使用。

### `multinomial_nb`

- 模型介绍：适用于非负计数或频次特征的朴素贝叶斯分类模型，常见于词频、计数型输入。
- 适用场景：特征天然是非负计数、频次或离散出现次数，且希望比较朴素贝叶斯计数模型时使用。

### `glm_classifier`

- 模型介绍：广义线性分类模型，偏重统计解释和参数可读性。
- 适用场景：二分类任务、需要清晰统计解释、特征矩阵共线性风险可控、且不依赖复杂非线性边界时使用。

### `adaboost_classifier`

- 模型介绍：通过逐轮提升弱分类器来提高分类效果的集成模型，适合做中小规模非线性分类。
- 适用场景：边界存在一定非线性、希望在随机森林之外再比较一种提升类模型时使用。

### `xgboost_classifier`

- 模型介绍：基于梯度提升树的高性能分类模型，通常在表格数据上表现较强，但依赖插件和运行时支持。
- 适用场景：结构化表格任务、特征较丰富、需要更强拟合能力、且当前 DolphinDB 环境已启用相关插件时使用。

### `svm_classifier`

- 模型介绍：基于支持向量机的分类模型，适合处理中小样本和较复杂边界，但对参数和尺度较敏感。
- 适用场景：样本量不大、特征已完成良好缩放、希望比较核方法与树模型或线性模型差异时使用。

## 脚本块选择策略

- 先运行标签分布块；标签只有单一类别、缺失严重或类别定义不清时停止并请求确认。
- 分类模型训练前必须确保标签列是从 0 开始的整数编码。原始标签为字符串、SYMBOL、布尔语义或非连续编码时，先运行“分类标签编码落地”块或清洗脚本的标签编码块，并把 `webLabelCol` 改为编码后的标签列。
- 训练函数必须使用 `sqlDS(<select * from webTrain>)` 生成的数据源；预测输入必须是 table，例如 `webVal` 或 `webTest`，不要传 `webVal[webFeatureCols]`。
- 训练前运行训练/测试切分和切分后标签分布块，检查测试集是否保留关键类别。
- 默认使用随机森林分类块作为稳健基线。
- 多分类至少报告 accuracy 和混淆矩阵；二分类额外报告 precision、recall 和 F1，并说明正类定义。
- 类别明显不均衡时，只使用训练集欠采样作为默认处理手段：先完成 train/val/test 切分，再运行“分类训练集欠采样”块，生成 `webTrainForModel` 和 `webFinalTrainForModel`；不要改变验证集和测试集的原始分布。
- 欠采样后，网格搜索和最终训练块会优先使用 `webTrainForModel` / `webFinalTrainForModel`。聊天输出必须报告欠采样前后标签分布、训练行数变化、少数类 recall/F1 是否改善，以及多数类样本被丢弃带来的稳定性风险。
- 当前样本打分块只用于用户提供当前特征或待评分数据时；输出应说明特征口径与训练口径是否一致。
- 最后使用分类摘要块，在聊天中报告数据范围、特征数量、标签分布、指标、局限和下一步建议。
- 需要比较模型时，先运行模型函数可用性和候选模型表；不可用模型从候选中排除并在聊天中说明。
- 网格搜索输出候选结果表和最佳候选选择表。
- 时间列存在且任务有预测语义时，优先使用 time_based 的 train/val/test 切分；否则显式说明使用 random 切分。
- 风险报告是最终摘要前的必选块；低召回、低精确率或低准确率时必须说明风险和下一步。

## 默认网格

默认开启轻量网格搜索，候选上限为 20。调用方显式指定单模型时，可以只评估该模型，但必须说明跳过其他候选的原因。

- `random_forest`：`numTrees=[100,200,300]`，`maxDepth=[6,8,12]`，`maxFeatures=[0.0,0.5]`，`numBins=[32]`，`minImpurityDecrease=[0.0]`。Web 示例默认执行 `numTrees` 和 `maxDepth`，其他参数记录在 `params_json`，仅在确认运行时支持时加入训练调用。
- `logistic_regression`：`maxIter=[100,200]`，`regularizationCoeff=[0.001,0.01,0.1]`。
- `gaussian_nb`：无超参数网格，作为快速基线候选。
- `multinomial_nb`：不进入默认网格；仅在特征全部是非负计数或频次，且用户明确需要朴素贝叶斯计数模型时手动加入。
- `glm_classifier`：不进入默认网格；仅在已排除完整 one-hot 共线性、特征矩阵可逆性风险较低且用户需要统计解释时手动加入。
- `adaboost_classifier`：`numTrees=[100,200]`，`maxDepth=[2,3]`，`learningRate=[0.05,0.1]`。

插件模型 `xgboost_classifier` 和 `svm_classifier` 不进入默认 Web 网格；如果用户明确要求，先检查插件和函数可用性，不可用时记录 `plugin_disabled` 或 `function_unavailable`。

## 模型选择输出

- 网格候选报告必须包含候选 ID、模型 ID、函数名、参数、选择指标、验证集分数、排序、是否最佳和耗时。
- 模型选择摘要必须说明 `selectedModelId`、`fallbackModelId`、`candidateModelIds`、最佳候选、跳过候选和选择原因。
- 最终聊天结论使用 test 评估结果；验证集分数只用于选型。
