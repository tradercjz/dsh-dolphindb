# 回归模型目录

默认顺序：

1. `random_forest`：使用 `randomForestRegressor` 的稳健非线性基线。
2. `ridge`：可用时作为稳定线性基线。
3. `lasso`：可用时作为稀疏线性基线。


## 模型介绍与适用场景

### `random_forest`

- 模型介绍：基于多棵决策树集成的非线性回归模型，能够自动学习变量之间的阈值关系和交互关系。
- 适用场景：表格型回归任务、非线性关系明显、特征之间可能存在复杂交互、希望先得到一个稳健基线时优先使用。

### `ridge`

- 模型介绍：带 L2 正则的线性回归模型，适合在保留全部特征的前提下缓解多重共线性。
- 适用场景：连续数值特征较多、特征之间相关性较强、需要稳定线性对照模型、希望结果具有较好解释性时使用。

### `lasso`

- 模型介绍：带 L1 正则的线性回归模型，会把一部分弱特征系数压到 0，具备一定的稀疏选择效果。
- 适用场景：特征较多、希望获得更稀疏的线性模型、希望初步筛掉弱贡献特征时使用。

### `elastic_net`

- 模型介绍：结合 L1 和 L2 正则的线性回归模型，兼顾稀疏性和对共线性的稳定性。
- 适用场景：既存在共线性，又希望得到一定特征筛选效果的中高维表格回归任务。

### `glm_regression`

- 模型介绍：广义线性模型回归，强调参数可解释性和显式的统计建模形式。
- 适用场景：需要线性解释、需要把业务关系表达为相对明确的统计模型、且数据关系近似线性时使用。

### `adaboost_regressor`

- 模型介绍：通过逐轮关注高误差样本来提升拟合能力的集成回归模型，适合做中小规模非线性拟合。
- 适用场景：样本量中等、非线性关系存在、希望在随机森林之外再比较一种集成方法时使用。

### `xgboost_regression`

- 模型介绍：基于梯度提升树的高性能回归模型，通常对表格数据有较强拟合能力，但依赖插件和运行时支持。
- 适用场景：表格特征较丰富、需要更强拟合能力、并且当前 DolphinDB 环境已启用对应插件时使用。

### `svm_regression`

- 模型介绍：基于支持向量机的回归模型，适合处理中小样本和较复杂的非线性边界，但对参数和尺度较敏感。
- 适用场景：样本量不大、特征已做良好缩放、希望比较核方法与树模型或线性模型差异时使用。

## 脚本块选择策略

- 先运行目标分布块；目标列非数值、缺失严重或范围明显异常时停止或请求确认。
- 训练函数必须使用 `sqlDS(<select * from webTrain>)` 生成的数据源；预测输入必须是 table，例如 `webVal` 或 `webTest`，不要传 `webVal[webFeatureCols]`。
- 训练前运行训练/测试切分块，保留可复现的随机种子和样本量说明。
- 默认使用随机森林回归块作为稳健基线。
- 评估时同时报告 MAE、RMSE、R2 和 MAPE；当目标包含 0 或接近 0 时说明 MAPE 可能失真。
- 使用残差摘要和 top/bottom 误差样本块定位系统性误差，但不要把单次样本误差过度解释。
- 最后使用回归摘要块，在聊天中报告目标分布、特征数量、指标、误差样本、局限和下一步建议。
- 需要比较模型时，先运行模型函数可用性和候选模型表；线性类模型通常需要清洗后的连续数值特征和尺度处理。
- 网格搜索输出候选结果表和最佳候选选择表。
- 时间列存在且任务有预测语义时，优先使用 time_based 的 train/val/test 切分；否则显式说明使用 random 切分。
- 风险报告是最终摘要前的必选块；R2 低、MAPE 高或误差样本集中时必须说明风险和下一步。

## 默认网格

默认开启轻量网格搜索，候选上限为 20。调用方显式指定单模型时，可以只评估该模型，但必须说明跳过其他候选的原因。

- `random_forest`：`numTrees=[100,200,300]`，`maxDepth=[8,12]`，`maxFeatures=[0.0,0.5]`，`numBins=[32]`，`minImpurityDecrease=[0.0]`。Web 示例默认执行 `numTrees` 和 `maxDepth`，其他参数记录在 `params_json`，仅在确认运行时支持时加入训练调用。
- `ridge`：旧版 registry 使用 `lambda=[0.1,1.0,10.0]`；当前 Web DOS 训练参数映射为 `alpha=[0.1,1.0,10.0]`。
- `lasso`：旧版 registry 使用 `lambda=[0.01,0.1,1.0]`；当前 Web DOS 训练参数映射为 `alpha=[0.01,0.1,1.0]`。
- `elastic_net`：旧版 registry 使用 `alpha=[0.1,0.5,0.9]` 和 `lambda=[0.01,0.1,1.0]`；当前 Web DOS 映射为 `l1Ratio=[0.1,0.5,0.9]` 和 `alpha=[0.01,0.1,1.0]`。
- `glm_regression`：`family=["gaussian"]`，`link=["identity"]`，`maxIter=[200]`，`tolerance=[1e-6,1e-5]`。
- `adaboost_regressor`：`numTrees=[100,200]`，`maxDepth=[2,3]`，`learningRate=[0.05,0.1]`。

插件模型 `xgboost_regression` 和 `svm_regression` 不进入默认 Web 网格；如果用户明确要求，先检查插件和函数可用性，不可用时记录 `plugin_disabled` 或 `function_unavailable`。

## 模型选择输出

- 网格候选报告必须包含候选 ID、模型 ID、函数名、参数 JSON、选择指标、验证集分数、排序、是否最佳和耗时。
- 模型选择摘要必须说明 `selectedModelId`、`fallbackModelId`、`candidateModelIds`、最佳候选、跳过候选和选择原因。
- 最终聊天结论使用 test 评估结果；验证集分数只用于选型。
