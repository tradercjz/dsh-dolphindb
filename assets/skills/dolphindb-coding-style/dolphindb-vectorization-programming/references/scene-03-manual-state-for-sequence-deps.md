# 场景 03：对序列中的累计、前值与分段关系，仍手工维护状态

场景介绍：

代码在处理一条序列，或者每个分组内部的一条序列。当前值会依赖前值、相邻值、累计值或分段状态。脚本里常见 `state`、`tmp`、`prevVal`、结果数组和显式循环。这个场景只处理仍能留在向量和高阶函数层的状态问题：标准累计、连续段、阈值分段、终值归约、全路径输出。单步状态特别重、已经决定走 `JIT` 时，转到 `scene-11`。

以下是一些典型的例子：

## 1. 累计结果仍手工维护状态变量

目标：计算向量的累计最大值。

低效写法：

```dos
v = 5 2 7 3 9 4
tmp = v[0]
re = array(INT, v.size())
for(i in 0:v.size()-1){
    if(v[i] > tmp)
        tmp = v[i]
    re[i] = tmp
}
```

分析：这段代码已经是标准累计模式。循环只是在维护“到当前位置为止的最大值”。

解决方案：

```dos
v = 5 2 7 3 9 4
re = cummax(v)
```

分析：`cummax` 直接表达了同一件事。遇到这类累计模式，先查有没有现成的 `cum*` 函数。

## 2. 连续段标记仍手工循环

目标：给序列的连续上升、下降或持平区间打标。

低效写法：

```dos
v = 3 5 6 4 4 7 9
trend = array(INT, v.size())
for(i in 1:v.size()-1){
    if(v[i] > v[i-1])
        trend[i] = 1
    else if(v[i] < v[i-1])
        trend[i] = -1
    else
        trend[i] = trend[i-1]
}
```

分析：代码在手工比较相邻值，再把结果沿序列传播。这类问题通常不必自己维护循环状态。

解决方案：

```dos
v = 3 5 6 4 4 7 9
trend = signum(ffill(next(deltas(v))))
```

分析：相邻关系、缺口补齐和符号判断都可以直接走向量函数。连续段问题优先检查 `deltas`、`next`、`ffill`、`signum`。

## 3. 阈值重置累计仍手工维护分段状态

目标：累计到某个阈值后重置分段，再在段内继续累计。

低效写法：

```dos
a = 1 3 4 2 2 1 1 1 1 6 8
seg = 0
sumv = 0
re = array(INT, a.size())
for(i in 0:a.size()-1){
    if(sumv + a[i] > 4){
        seg += 1
        sumv = 0
    }
    sumv += a[i]
    re[i] = sumv
}
```

分析：代码自己维护分段号和段内累计值。阈值重置累计通常可以改成“先分段，再段内累计”。

解决方案：

```dos
a = 1 3 4 2 2 1 1 1 1 6 8
re = segmentby(cumsum, a, volumeBar(a, 4))
```

分析：`volumeBar` 先把阈值分段表达出来，`segmentby(cumsum, ...)` 再做段内累计。比手工维护状态更稳。

## 4. 只需要最终递推结果仍手工写终值循环

目标：递推计算只需要最后一个结果。

低效写法：

```dos
v = 1 2 3 4 5
state = 0
for(x in v){
    state = state + x
}
re = state
```

分析：中间路径根本不会被使用，循环只是在做终值归约。

解决方案：

```dos
v = 1 2 3 4 5
re = reduce(add, v)
```

分析：先把外层迭代交给 `reduce`。如果单步状态特别重，再转到 `scene-11`。

## 5. 需要完整递推路径仍手工维护结果数组

目标：递推计算要保留每一步结果。

低效写法：

```dos
v = 1 2 3 4 5
state = 0
re = array(INT, v.size())
for(i in 0:v.size()-1){
    state = state + v[i]
    re[i] = state
}
```

分析：代码自己同时维护“上一步状态”和“完整结果数组”。这是典型的迭代路径输出问题。

解决方案：

```dos
v = 1 2 3 4 5
re = accumulate(add, v)
```

分析：`accumulate` 直接返回每一步的结果。若单步函数本身很重，再转到 `scene-11`。

## 6. 函数索引

| 函数 / 模式 | 什么时候查 | 解决什么问题 |
| --- | --- | --- |
| `cummax` / `cummin` / `cumsum` | 标准累计模式还在手工维护状态变量 | 直接替换累计循环 |
| `accumulate` | 需要完整迭代路径 | 返回每一步递推结果 |
| `reduce` | 只需要最终递推结果 | 返回终值 |
| `deltas` / `next` / `prev` | 相邻关系、前值、回看关系 | 相邻比较与位移 |
| `ffill` / `bfill` | 连续段传播还在手工回填 | 填补相邻缺口 |
| `signum` | 趋势或方向仍手工打标 | 符号判断 |
| `segmentby` | 已经有了分段标识 | 段内累计或段内聚合 |
| `volumeBar` | 阈值重置累计还在手工分段 | 先把阈值问题转成分段 |
