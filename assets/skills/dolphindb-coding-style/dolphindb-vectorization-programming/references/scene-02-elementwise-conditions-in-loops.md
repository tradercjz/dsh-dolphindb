# 场景 02：对一批独立数据进行逐元素条件判断、过滤与赋值

场景介绍：

数据已经在向量、表列、矩阵这些可批量处理的对象里。每个位置的结果只看当前元素和一套固定规则。代码里却还保留 `for`、逐值 `if`、逐值 `append!`、逐值写回。这个场景优先检查：条件分支、布尔过滤、规则过滤、条件替换。整列类型修复、时间恢复、文本清洗转到 `scene-06`。

以下是一些典型的例子：

## 1. 按元素条件分支写成循环

目标：逐位置比较两个向量，返回每个位置较大的值。

低效写法：

```dos
a = rand(100, 1000000)
b = rand(100, 1000000)
re = array(INT, a.size())
for(i in 0:a.size()-1){
    if(a[i] > b[i])
        re[i] = a[i]
    else
        re[i] = b[i]
}
```

分析： 代码使用了显式循环，逐位置比较和赋值，没有利用向量化的条件表达和批量赋值功能。

解决方案：

```dos
a = rand(100, 1000000)
b = rand(100, 1000000)
re = iif(a > b, a, b)
```

分析：条件表达式一次作用在整批数据上。结果直接按向量返回，不再逐位置写回。

同一类问题在批量接口里也很常见。比如函数入参已经是向量，还继续写普通 `if`，这时优先检查是否应该改成 `iif`。

## 2. 满足条件的元素手工收集

目标：保留向量中有效且大于 0 的元素。

低效写法：

```dos
v = 1 NULL -2 5 8 NULL -1 3
re = array(INT)
for(x in v){
    if(isValid(x) && x > 0)
        re.append!(x)
}
```

分析：手工判断条件、手工 `append!`。


解决方案：

```dos
v = 1 NULL -2 5 8 NULL -1 3
re = v[isValid(v) && v > 0]
```

如果目标只是去掉空值，也可以直接写成：

```dos
re = dropna(v)
```

分析：条件直接变成布尔向量。过滤结果一次返回，不再逐元素拼接。

同一路线也适用于矩阵和表。向量、矩阵优先查 `dropna`，表优先查布尔筛选或 SQL 路径。

## 3. 规则过滤按行判断

目标：按证券品种对应的不同交易时段过滤表数据。

低效写法：

```dos
n = 100000
time = 2024.01.02 08:00:00.000 + 300 * 0..(n-1)
sym = take(`a`b`c, n)
price = rand(100.0, n)
tb = table(sym, time, price)

filter = {"a" : [09:30m : 11:30m, 13:00m : 15:00m],
          "b" : [09:30m : 12:00m, 13:00m : 16:00m],
          "c" : [09:30m : 11:30m]}

res = table(0:0, tb.colNames(), tb.colTypes())
for(i in 0:tb.size()-1){
    m = minute(tb.time[i])
    s = tb.sym[i]
    if(between(m, filter[s]).any())
        tableInsert(res, tb.row(i))
}
```

分析：每一行都要做一次规则查找、一次条件判断，还要逐条写入结果表。

解决方案：

```dos
filter1 = {"a": 09:30m : 11:30m, "b": 09:30m : 12:00m, "c": 09:30m : 11:30m}
filter2 = {"a": 13:00m : 15:00m, "b": 13:00m : 16:00m, "c": 09:30m : 11:30m}

select * from tb
where conditionalFilter(time.minute(), sym, filter1)
   or conditionalFilter(time.minute(), sym, filter2)
```

分析：规则字典直接进入批量过滤函数。条件判断在整列上完成，不再逐行跑脚本。


## 4. 函数索引

| 函数 / 模式 | 什么时候查 | 解决什么问题 |
| --- | --- | --- |
| `iif` | 逐元素条件分支、条件替换、条件打标 | 批量条件表达 |
| 布尔索引 `x[cond]` | 满足条件的元素仍手工收集 | 批量过滤 |
| `dropna` | 空值过滤仍手工遍历 | 向量、矩阵空值过滤 |
| `conditionalFilter` | 规则字典驱动的过滤还在按行判断 | 批量规则过滤 |
| `rowOr` / `at` | 多列任一列命中条件时还在逐行扫描 | 批量定位异常行或异常值 |
| `clip` | 上下限裁剪还在写多段 `if` | 区间裁剪 |
| `where` / `select` | 条件已经落在表上，代码还在逐行过滤 | 表级条件过滤 |
