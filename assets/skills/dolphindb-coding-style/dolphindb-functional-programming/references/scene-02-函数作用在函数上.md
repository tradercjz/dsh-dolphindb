# 场景 02：函数作用在函数上

## 目录

1. 函数作为可传递对象
2. 函数运算符
3. 部分应用与参数绑定
4. 动态获取、动态调用和调用代码生成

## 适用任务

当前任务需要把函数作为对象传递、固定、组合、返回、动态获取、动态调用，或动态生成后续调用代码。

## 入口选择

| 任务 | 常用入口 | 判断标准 |
| --- | --- | --- |
| 写短局部函数 | lambda / 匿名函数 | 逻辑短，使用范围局部 |
| 将函数作为运算符使用 | 函数运算符 | 单目或双目函数不包含 `mutable` 参数 |
| 固定部分参数 | 部分应用 / `partial` | 需要生成一个新函数签名 |
| 保留默认参数 | `DFLT` | 固定部分可选参数，同时保留其他默认行为 |
| 封装状态 | `partial` + 可变容器 | 函数调用之间需要共享状态 |
| 通过名称获取函数 | `funcByName` | 函数名来自运行期数据 |
| 通过字符串解析函数 | `parseExpr(...).eval()` | 函数定义来自字符串 |
| 立即执行动态函数 | `call`、`()`、`at` | 函数对象已经确定，需要组织实参执行 |
| 生成调用代码 | `makeCall` / `makeUnifiedCall` | 需要构造后续由 SQL 或表达式系统执行的调用 |

## 1. 函数作为可传递对象

适用内容：

- 匿名函数
- lambda
- 函数对象传递
- 函数对象返回

判断规则：

- 函数只在当前表达式中使用时，优先使用 lambda 或匿名函数。
- 函数体较长、包含多步逻辑或需要复用时，定义具名函数。
- 函数作为参数传给高阶函数时，应同时确认输入拆分方式和结果合并方式。

### 例 1：匿名函数按列输出结果

```dos
m = matrix(1 2 3 4, 5 6 7 8).rename!(`val1`val2)
byColumn(def(x){return take(x.sum(), x.size())}, m)
```

匿名函数定义局部列级逻辑，`byColumn` 指定按列应用。

### 例 2：lambda 写短局部逻辑

```dos
byColumn(x->take(x.sum(), x.size()), m)
```

函数体只有一个返回表达式时，lambda 比匿名函数定义更简洁。

## 2. 函数运算符

适用内容：

- 单目函数运算符
- 双目函数运算符
- 函数模式参与运算符表达式
- 运算符优先级检查

判断规则：

- 单目或双目函数不包含 `mutable` 参数时，可以作为函数运算符使用。
- 内置双目函数存在对应普通运算符时，函数运算符沿用该普通运算符优先级。
- 内置双目函数没有对应普通运算符时，优先级等同于加法运算符。
- 单目函数运算符优先级最低；`not`、`neg` 与 `!`、`-` 的优先级不同。
- 多个单目函数运算符连续出现时，实际从右向左执行。
- 表达式存在优先级歧义时，改用链式表达或普通函数调用。

### 例 3：双目函数作为运算符

```dos
1 + 2
1 add 2
1 {x,y->x+y} 2
```

三种写法语义相同。函数作为运算符使用时，函数参数来自运算符左右两侧。

### 例 4：`neg` 与 `-` 的优先级不同

```dos
- 3 + 5
neg 3 add 5
```

`-` 先于加法执行，`neg` 作为单目函数运算符时优先级最低。复杂表达式中应避免仅凭直觉判断绑定关系。

### 例 5：函数模式参与运算符表达式

```dos
t1 = table(`A`B`C as id, 1000 2000 1000 as qty, 50.5 60.5 100.0 as price)
t2 = table(`A`B`C as id, 1000 2100 1000 as qty, 50.5 60.5 100.0 as price)
eq:V(t1, t2).all:H().not().at()
at not all:H t1 eq:V t2
```

两种写法等价。面向代码生成或人工维护时，优先保留链式表达。

## 3. 部分应用与参数绑定

适用内容：

- 固定部分参数
- 保留默认参数
- 生成更适合高阶函数调用的新函数
- 用部分应用封装状态

判断规则：

- 需要提前固定部分参数时，使用部分应用。
- 内置函数存在多个可选参数时，用 `DFLT` 明确保留默认参数。
- 部分应用与对象方法风格混用时，检查对象与后续参数的绑定顺序。
- 需要跨调用保留状态时，可使用 `partial` 绑定可变容器，并显式声明状态位置。

### 例 6：部分应用固定参数

```dos
// rank(X, [ascending=true], [groupNum], [ignoreNA=true], [tiesMethod='min'],
//      [percent=false], [precision])
f = rank{ascending=DFLT, groupNum=DFLT, ignoreNA=DFLT, percent=true, precision=DFLT}
f(1 5 3 3)
f(1 5 3 3, 'average')
```

`DFLT` 保留未固定参数的默认行为，`percent=true` 固定当前场景需要的参数。

### 例 7：部分应用封装状态

```dos
def myCumsum(mutable state, x){
    state[0] += x
    return state[0]
}
f = partial(myCumsum, [0])
f(1)
f(2)
f(3)
```

`partial` 将状态容器绑定到函数中，后续调用共享同一状态。

### 例 8：链式调用中控制绑定顺序

```dos
m = rand(1.0, 4:5)
m.{skew{,false}}:H()
```

`skew{,false}` 先生成新函数，再由 `:H` 将矩阵按行传入该函数。对象方法风格与部分应用相邻时，应检查绑定顺序。

## 4. 动态获取、动态调用和调用代码生成

适用内容：

- `funcByName`
- `parseExpr`
- `call`
- `unifiedCall`
- `at`
- `makeCall`
- `makeUnifiedCall`

判断规则：

- 函数名来自数据时，使用 `funcByName`。
- 函数定义来自字符串时，使用 `parseExpr(...).eval()` 得到函数对象。
- 需要立即执行函数对象时，使用 `call`、`()` 或 `at`。
- 映射对象为函数时，`at` 相当于 `unifiedCall`，第二个参数负责承载函数实参。
- 需要生成后续表达式或 SQL 调用代码时，使用 `makeCall` 或 `makeUnifiedCall`。
- `at` 的第二个参数是实参集合；单个实参本身为元组时，需要用 `enlist` 包装。

### 例 9：通过名称获取函数定义

```dos
names = `sin`cos`tan
v = 1..10
funcByName:U(names).{call{, v}}:U()
```

函数名称由 `names` 提供，`funcByName` 在运行期取得函数对象，`call{, v}` 固定待处理数据。

### 例 10：通过字符串解析 lambda

```dos
funcDef = "x->1 + x + x*x"
parseExpr(funcDef).eval().call(2)
```

字符串先解析为表达式，再求值得到函数对象，最后通过 `call` 执行。

### 例 11：动态调用函数对象

```dos
f = parseExpr("{x,y->(x - y)/(x + y)}").eval()
call(f, 3.0, 2.0)
f(3.0, 2.0)
at(f, (3.0, 2.0))
```

三种写法都执行同一个函数对象，差异在实参组织形式。

### 例 12：单个元组实参需要包装

```dos
f = {x->x.head()\x.tail()}
x = (1,2,3)
at(f, enlist x)
```

函数只接收一个参数，且该参数本身是元组。`enlist x` 防止 `at` 将元组元素拆成多个实参。

### 例 13：生成函数调用代码

```dos
f = parseExpr("{x,y->(x-y)/(x+y)}").eval()
makeCall(f, sqlCol("qty1"), sqlCol("qty2"))
makeUnifiedCall(f, (sqlCol("qty1"), sqlCol("qty2")))
makeUnifiedCall(f, sqlTuple(`qty1`qty2))
```

`call` / `at` 执行函数；`makeCall` / `makeUnifiedCall` 构造后续执行的调用表达式。

## 选择清单

处理“函数作用在函数上”的任务时，按以下顺序判断：

1. 当前需要短局部函数，还是可复用函数对象。
2. 当前需要固定参数，还是需要跨调用保留状态。
3. 当前函数在编码期已知，还是运行期才确定。
4. 当前目标是立即执行，还是生成后续调用表达式。
5. 当前参数组织方式是否会改变函数实参数量。
